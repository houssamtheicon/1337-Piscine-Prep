GCC Compilation Guide

Understanding GCC flags is essential for compiling your C projects correctly and debugging them effectively during the Piscine.

Standard Compilation Flags

The Piscine enforces strict compilation with these mandatory flags:

gcc -Wall -Wextra -Werror -o program file1.c file2.c
FlagPurpose
-WallEnable most common compiler warnings
-WextraEnable additional warnings beyond -Wall
-WerrorTreat all warnings as errors — compilation fails if any warning exists

Note: Since -Werror treats warnings as errors, your code must compile with zero warnings. This is checked during evaluation.

Creating Object Files

Use the -c flag to compile source files into object files without linking:

gcc -Wall -Wextra -Werror -c ft_putchar.c   # produces ft_putchar.o
gcc -Wall -Wextra -Werror -c ft_putstr.c    # produces ft_putstr.o

Linking Libraries

Link object files and libraries into a final executable:

# Link object files
gcc -o program main.o ft_putchar.o ft_putstr.o

# Link against a library
gcc -o program main.o -L/path/to/lib -lmylib

-L specifies the library directory, -l specifies the library name (without lib prefix or .a suffix).

Debug Symbols

Add the -g flag to include debug symbols for GDB:

gcc -Wall -Wextra -Werror -g -o program file.c

Sanitizers

Sanitizers help detect memory errors at runtime. Use them during development:

# Address sanitizer — detects buffer overflows, use-after-free
gcc -Wall -Wextra -Werror -g -fsanitize=address -o program file.c

# Leak sanitizer — detects memory leaks
gcc -Wall -Wextra -Werror -g -fsanitize=leak -o program file.c

Tip: Sanitizers can slow execution significantly. Use them for testing and disable them for the final submission binary.

Optimization Levels

LevelDescription
-O0No optimization (default). Best for debugging.
-O1Basic optimization — reduces code size and execution time.
-O2Further optimization — balances speed and size.
-O3Maximum optimization — can increase binary size.

Preprocessor & Assembly

# Run preprocessor only (expands macros, includes)
gcc -E file.c -o file.i

# Compile to assembly only
gcc -S file.c -o file.s

Example Makefile Integration

CC = gcc
CFLAGS = -Wall -Wextra -Werror
SRCS = main.c ft_putchar.c ft_putstr.c
OBJS = $(SRCS:.c=.o)
NAME = program

all: $(NAME)

$(NAME): $(OBJS)
	$(CC) $(CFLAGS) -o $(NAME) $(OBJS)

%.o: %.c
	$(CC) $(CFLAGS) -c $< -o $@

clean:
	rm -f $(OBJS)

fclean: clean
	rm -f $(NAME)

re: fclean all
