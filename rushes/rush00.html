Rush 00

A basic algorithmic project focused on printing geometric patterns using nested loops and conditionals. Typically assigned during week 1 of the Piscine.

Overview

Rush 00 requires you to write a program that displays a rectangle or grid made of specific characters based on dimensions given as parameters. The challenge lies in correctly placing the right characters at corners, edges, and interior positions using conditional logic within nested loops.

Key Concepts

Loops Nested Loops Conditions Function Design Team Coordination

Common Approach

The typical solution involves breaking the grid into three row types: top, middle, and bottom. The top and bottom rows are unique (corners with connecting characters), while the middle rows use a different pattern. Use ft_putchar to output each character and structure your code around a function that takes width and height as parameters.

Split responsibilities with your partner: one handles the character selection logic, the other manages the loop structure and edge cases. Integrate early and test with small dimensions first.

Testing Tips

  • Test with small grids first: 1x1, 1x5, 5x1, 3x3
  • Verify output character-by-character against the subject
  • Check trailing newlines — the output must end with a newline
  • Test with size 0 or negative values — your program should handle gracefully or match expected behavior
  • Use diff to compare your output with expected output

Common Pitfalls

  • Wrong character output — double-check which character goes to corners, edges, and interior
  • Edge case handling — size 0 and size 1 produce very different outputs; test them explicitly
  • Off-by-one errors in grid dimensions — ensure the loops iterate exactly width and height times
  • Missing newlines after each row — each row must end with a newline character
  • Mixing up row and column logic — keep a clear mental model of which loop controls rows vs columns
