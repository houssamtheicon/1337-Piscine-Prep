Final Exam — End of Piscine

Comprehensive exam covering the entire Piscine curriculum. This is the most challenging exam — expect exercises spanning all modules from C 00 through C 13, including linked lists, trees, file I/O, and function pointers. 4 hours, graded automatically.

Exam Rules: The final exam is longer (4 hours) and covers more material than previous exams. You will need to solve exercises across all difficulty levels. Time management and prioritization are critical to success.

Mindset Checklist

  • Review all C modules before exam day — especially C 07 (malloc), C 11 (function pointers), C 12 (linked lists), and C 13 (trees)
  • Practice complete mock exams under timed conditions — aim for 4 hours non-stop
  • Prioritize exercises: start with levels 0-2 to secure points, then tackle levels 3-4, and attempt level 5 last
  • Have a strategy for each exercise type: string manipulation, memory allocation, linked lists, tree traversal
  • Know your debugging shortcuts: limited write for output, mental trace for logic errors
  • Bring your knowledge of common patterns: ft_split, ft_itoa, ft_list_remove_if, btree_insert_data

Level Breakdown

Level 0 Fundamentals

Basic output and warm-up. Secure these points first.

  • aff_a / aff_z
    Display specific characters from strings
  • ft_countdown / ft_print_numbers
    Basic digit display
  • hello / only_a / only_z
    Simple character output

Level 1 Basic Functions

Strings, pointers, and simple loops.

  • ft_strcpy / ft_strlen
    Core string operations
  • ft_swap / ft_putstr
    Basic pointer and output functions
  • rev_print / repeat_alpha
    String transformation exercises
  • rot_13 / rotone
    Character rotation ciphers

Level 2 Intermediate

String comparisons, atoi, bits, and simple data structures.

  • ft_atoi
    String to integer conversion
  • ft_strcmp / ft_strdup
    Comparison and duplication
  • print_bits / reverse_bits / swap_bits
    Bit manipulation
  • alpha_mirror / last_word / ulstr
    Advanced string transformations

Level 3 Advanced

Memory allocation, base conversion, linked list basics.

  • add_prime_sum / epur_str
    Math and string processing
  • ft_atoi_base / print_hex
    Base conversion
  • ft_range / ft_rrange
    Allocated integer arrays
  • ft_list_size / ft_list_push_front
    Linked list fundamentals
  • paramsum / pgcd
    Argument processing and GCD

Level 4 Expert

Complex allocation, sorting, list manipulation, function pointers.

  • ft_itoa / ft_split
    Complex allocation patterns
  • ft_list_remove_if / sort_list
    Advanced list operations
  • ft_foreach / ft_map (function pointers)
    Higher-order functions
  • ft_convert_base
    Base-to-base conversion with malloc

Level 5 Master

Binary trees, complex sorting, multi-file programs, advanced algorithms.

  • btree_insert_data / btree_search_item
    Binary search tree operations
  • btree_apply_infix / btree_level_count
    Tree traversal and measurement
  • ft_advanced_sort_string_tab
    Advanced string sorting with callbacks
  • ft_sorted_list_merge / ft_list_sort
    Complex linked list algorithms
  • ft_show_tab (struct display)
    Structure-based output programs

Common Mistakes: Running out of time on lower levels (wasting time on level 5 when level 3-4 points are still available), memory leaks in complex allocation exercises, incorrect tree pointer manipulation, forgetting edge cases in btree operations (empty tree, single node), norm errors in multi-file submissions, not re-reading the subject carefully.

Timed Practice Recommendations

Preparation for the final exam requires systematic practice across all levels. Simulate exam conditions.

  • Week before: Review all C modules C 00-C 13 — focus on weak areas
  • Session 1: Levels 0-2 mock — complete in 60 minutes
  • Session 2: Levels 3-4 mock — complete in 90 minutes
  • Session 3: Level 5 exercises — practice each one individually
  • Session 4: Full 4-hour mock exam — all levels, no breaks, no external help
  • Session 5: Review mistakes from Session 4 and practice weak exercises
