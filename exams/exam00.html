Exam 00 — First Machine Exam

The first exam typically covers Shell basics and beginner C. 3 hours, graded automatically.

Exam Rules: You must cd to the correct directory, name your files exactly as required, and follow the Norm. No internet, no notes, no external tools. The exam uses a custom grading system — output must match expected results character by character.

Mindset Checklist

  • Read the subject carefully — understand input, output, and constraints before writing code
  • Start with the easiest level 0 exercises to build confidence and secure base points
  • Manage your time: 3 hours goes fast. If stuck on an exercise, move on and come back
  • Test edge cases: empty input, negative numbers, maximum values, special characters
  • Always re-read your code before submitting — one typo can cost you the exercise
  • Use the built-in norminette check before final submission

Level Breakdown

Level 0 Fundamentals

Basic output and simple programs. No arguments, no loops beyond basic iteration.

  • aff_a
    Display the first 'a' character in a string, or 'z' if none
  • aff_first_param
    Display the first command-line parameter
  • aff_last_param
    Display the last command-line parameter
  • ft_countdown
    Display digits from 9 down to 0
  • ft_print_numbers
    Display digits from 0 to 9

Level 1 Basic Functions

Simple string and memory operations. Single loops, basic pointer usage.

  • ft_strcpy
    Copy a string from source to destination
  • ft_strlen
    Return the length of a string
  • ft_swap
    Swap the values of two integers
  • ft_putstr
    Display a string character by character
  • repeat_alpha
    Repeat each letter by its position in the alphabet

Level 2 Intermediate Logic

String comparisons, conversions, and basic algorithms.

  • ft_atoi
    Convert a string to an integer
  • ft_strcmp
    Compare two strings lexicographically
  • ft_strdup
    Duplicate a string with malloc
  • ft_strrev
    Reverse a string in place
  • alpha_mirror
    Replace letters with their mirror in the alphabet (a->z, b->y, etc.)

Common Mistakes: Forgetting newline characters, incorrect file names, missing header includes, norm errors (too many lines, wrong indentation), off-by-one errors in loops, not handling empty strings.

Timed Practice Recommendations

Set a timer for 3 hours and practice completing all level 0-2 exercises in one sitting. Focus on speed and accuracy. Repeat this process 2-3 times before the actual exam.

  • Session 1: Complete all level 0 exercises within 30 minutes
  • Session 2: Complete all level 1 exercises within 45 minutes
  • Session 3: Full mock exam — all levels, 3 hours, no interruptions
