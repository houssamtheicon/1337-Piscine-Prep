Exam 02 — Third Machine Exam

Advanced topics: memory allocation, linked lists, and complex algorithms. Covers through C07+ material. 3 hours, graded automatically.

Exam Rules: This exam includes level 4 exercises that require malloc, linked list manipulation, and multi-file programs. Expect exercises like ft_split, ft_itoa, ft_list_remove_if, and sort_list.

Mindset Checklist

  • Master malloc patterns: ft_split, ft_range, ft_strjoin variations
  • Practice linked list operations: create, push, clear, remove_if, sort, merge
  • Understand how to use function pointers with linked list operations
  • Memorize the t_list structure: typedef struct s_list { void *data; struct s_list *next; } t_list;
  • Be comfortable with multi-file programs and header includes
  • Practice valgrind during practice — no leaks allowed

Level Breakdown

Level 0 Fundamentals

Warm-up exercises — basic output and simple programs.

  • aff_a
    Display the first 'a' character in a string
  • ft_countdown
    Display digits 9 down to 0
  • ft_print_numbers
    Display digits 0 to 9
  • hello
    Display "Hello World!"

Level 1 Basic Functions

Simple loops, pointer basics, string operations.

  • ft_strcpy
    Copy a string from source to destination
  • ft_strlen
    Return the length of a string
  • ft_swap
    Swap the values of two integers
  • ft_putstr
    Display a string character by character
  • rev_print
    Display a string in reverse

Level 2 Intermediate

String processing, atoi, bit manipulation, simple data structures.

  • ft_atoi
    Convert a string to an integer
  • ft_strcmp
    Compare two strings lexicographically
  • ft_strdup
    Duplicate a string with malloc
  • print_bits
    Display the bits of a byte
  • reverse_bits
    Reverse the bits of a byte
  • swap_bits
    Swap the first and last 4 bits of a byte

Level 3 Advanced

Allocation, base conversion, linked list basics, math.

  • add_prime_sum
    Sum all prime numbers up to n
  • ft_atoi_base
    Convert string in any base to integer
  • ft_list_size
    Return the number of elements in a linked list
  • ft_range
    Return an allocated array from min to max
  • ft_rrange
    Return an allocated array from max to min
  • pgcd
    Compute Greatest Common Divisor
  • print_hex
    Display a number in hexadecimal

Level 4 Expert

Complex algorithms, linked list manipulation, advanced string processing.

  • ft_itoa
    Convert an integer to an allocated string
  • ft_split
    Split a string by a charset into an allocated array
  • ft_list_remove_if
    Remove nodes from a linked list matching a condition
  • sort_list
    Sort a linked list using a comparison function
  • ft_atoi_base (advanced)
    atoi_base with full error handling

Allowed Functions

LevelAllowed Functions
0-1write
2write, malloc, free
3write, malloc, free
4write, malloc, free

Common Mistakes: Memory leaks in ft_split and ft_itoa, incorrect linked list pointer manipulation (especially removing head node), off-by-one in ft_range bounds, not handling negative numbers in ft_atoi_base, forgetting to null-terminate allocated strings, norm errors in multi-file submissions.

Timed Practice Recommendations

  • Session 1: Warm-up with levels 0-2 — complete in 45 minutes
  • Session 2: Level 3 exercises — focus on ft_range, ft_atoi_base, ft_list_size
  • Session 3: Level 4 exercises — ft_itoa, ft_split, ft_list_remove_if, sort_list
  • Session 4: Full mock exam — all levels, 3 hours with strict timing
