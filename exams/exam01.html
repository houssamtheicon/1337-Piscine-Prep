Exam 01 — Second Machine Exam

Strings, pointers, and slightly more complex logic. Expect exercises building on C01-C04. 3 hours, graded automatically.

Exam Rules: Same format as Exam 00 but with harder exercises. Topics include string manipulation, atoi, range generation, prime sums, and bit manipulation. All code must be Norm-compliant.

Mindset Checklist

  • Review string manipulation functions from C 02-C 04 before the exam
  • Know your ft_atoi implementation by heart — it appears in many forms
  • Practice bitwise operations: print_bits, reverse_bits, etc.
  • Understand malloc patterns for level 3 exercises like ft_range and ft_rrange
  • Budget time: aim for level 0-1 in 30 mins, level 2 in 60 mins, level 3 in 90 mins

Level Breakdown

Level 0-1 Review

Reinforces basics from Exam 00. Practice these for speed.

  • aff_a
    Display the first 'a' character in a string
  • ft_strcpy
    Copy a string from source to destination
  • ft_strlen
    Return the length of a string
  • ft_putstr
    Display a string character by character
  • repeat_alpha
    Repeat each letter by its alphabet position

Level 2 Medium Complexity

String processing, number conversion, prime numbers, bits.

  • add_prime_sum
    Sum all prime numbers up to a given integer
  • epur_str
    Remove extra spaces from a string (trim and collapse)
  • ft_atoi
    Convert a string to an integer
  • ft_strcpy
    Copy a string (possibly with different constraints)
  • ft_strdup
    Duplicate a string using malloc
  • hidenp
    Check if the first string is hidden in the second
  • print_bits
    Display the bits of a byte

Level 3 Advanced

Memory allocation, base conversion, list operations, and mathematical reasoning.

  • expand_str
    Expand spaces between words to three spaces
  • ft_atoi_base
    Convert a string in a given base to an integer
  • ft_list_size
    Return the number of elements in a linked list
  • ft_range
    Return an allocated array of ints from min to max
  • ft_rrange
    Return an allocated array from max to min (reversed range)
  • paramsum
    Sum and display the number of command-line arguments
  • pgcd
    Compute the Greatest Common Divisor (PGCD in French)
  • print_hex
    Display a number in hexadecimal format

Allowed Functions

LevelAllowed Functions
0-1write
2write, malloc, free
3write, malloc, free

Common Mistakes: Off-by-one in ft_range (inclusive vs exclusive bounds), forgetting to null-terminate duplicated strings, incorrect prime detection in add_prime_sum, bit order confusion in print_bits, improper handling of negative numbers in ft_atoi.

Timed Practice Recommendations

Practice with increasing difficulty. Focus on level 2-3 exercises that require malloc and more complex logic.

  • Session 1: Level 0-1 review — complete within 20 minutes
  • Session 2: Level 2 exercises — complete within 60 minutes
  • Session 3: Level 3 exercises — complete within 60 minutes
  • Session 4: Full mock exam — all levels, 3 hours, simulate exam conditions
