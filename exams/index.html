Exam Preparation

Machine exams are timed sessions (typically 3 hours) where you solve C exercises on a custom grading platform. An automated system called Moulinette evaluates your submissions. Each exam unlocks progressively harder exercises.

Exam Overview

Exam 00

First exam — basic C and shell. Tests fundamentals from C00 and Shell 00.

Beginner Level 0–4

Exam 01

Second exam — strings, pointers, and recursion. Covers C01–C05 material.

Intermediate Level 0–8

Exam 02

Third exam — advanced C, memory allocation, linked lists. C06–C12 material.

Intermediate Level 0–12

Final Exam

End-of-Piscine comprehensive exam. Covers everything from the entire Piscine.

Advanced Level 0–16

Rules & Grading

Grading system: Each exam exercise awards a base score. The harder the exercise, the more points. You can retry exercises with a score penalty. Your final rank depends on your total score across all solved exercises.

Moulinette: The automated grading system compiles your code with -Wall -Wextra -Werror and runs predefined tests. If your code does not compile, you get 0 for that exercise. Always test compilation before submitting.

Allowed functions: Each exercise specifies which external functions you may use. Using disallowed functions (e.g. printf when only write is allowed) results in a grade of -42 for that exercise.

Cheating consequences: Copying code, accessing forbidden files, or communicating with other students during an exam results in immediate disqualification and possible expulsion from the Piscine.

Exam Day Mindset

  • Start with what you know. Solve the easiest exercises first to secure points before tackling harder ones.
  • Read the subject carefully. Check function prototypes, allowed functions, and expected output format. One missing detail can cost you the exercise.
  • Compile frequently. Do not write everything then compile at the end. Compile after every few lines to catch errors early.
  • Test edge cases. Empty strings, negative numbers, INT_MIN, NULL pointers — these are exactly what Moulinette tests.
  • Manage time. If you are stuck on an exercise for more than 30 minutes, move on. You can always come back.
  • Stay calm. Exams are stressful by design. Take deep breaths, read the prompt again, and break the problem into smaller pieces.
  • Check your Norm. Moulinette runs Norminette. Even a perfectly working solution fails if it violates the Norm (25-line functions, forbidden keywords, etc.).

Level-Based Practice

Exams assign exercises by level. The higher your current level, the harder the exercise you receive. Practice these topics at each level:

Level Typical Exercises Skills Tested
0 ft_putchar, ft_print_alphabet, ft_strlen Basic output, loops, strings
1 ft_swap, ft_putstr, ft_strcpy Pointers, string copy
2 ft_atoi, ft_strcmp, ft_strrev Number conversion, comparison
3 ft_strcat, ft_strdup, ft_range Concatenation, memory allocation
4 ft_putnbr_base, ft_split, ft_itoa Base conversion, string splitting
5 ft_atoi_base, ft_print_hex, ft_list_push_front Complex conversion, linked lists
6–8 ft_list_remove_if, ft_sort_params, brainfuck Advanced data structures, interpreters
9–12 Options, ft_advanced_sort, ft_itoa_base Bit manipulation, advanced algorithms
13–16 Final exam exercises, comprehensive problems Everything combined
