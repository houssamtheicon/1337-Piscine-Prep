# 1337 Piscine Prep

An unofficial, community-driven preparation hub for the **42 / 1337 Piscine** — covering Shell, C programming, exams, rushes, peer evaluation, and more.

## Features

- **14 C Modules** (C00–C13) — topics from `ft_putchar` to doubly linked lists
- **Shell 00 & Shell 01** — Unix basics and scripting
- **Exam Prep** — Exam 00, Exam 01, Exam 02, and Final Exam with level breakdowns
- **Rush Guides** — Rush 00, Rush 01, Rush 02 with tips and strategies
- **Resource Guides** — Norminette, Git, GCC, Debugging (GDB/Valgrind), Peer Evaluation
- **Subject PDFs** — downloadable official subjects for Shell and C modules
- **Progress Tracking** — check off exercises per module (saved to localStorage)
- **Search** — quick page search with Ctrl+K / Cmd+K
- **Dark Mode** — light/dark theme toggle (persisted)
- **Week-by-Week Layout** — 4-week Piscine curriculum overview
- **Responsive Design** — works on desktop and mobile

## Site Structure

```
1337-Piscine-Prep/
├── index.html              # Landing page
├── shell/                  # Shell modules
├── c-days/                 # C modules (c00 – c13)
├── exams/                  # Exam prep pages
├── rushes/                 # Rush project guides
├── resources/              # Guides (norm, git, gcc, debugging, peer-eval)
├── subjects/               # Subject PDFs
├── css/style.css           # Styles
├── js/main.js              # Interactive features
└── data/exercises.json     # Exercise data
```

## Tech Stack

- **HTML / CSS / JavaScript** — no frameworks, fully static
- **Express.js** — local dev server only
- **Vercel** — deployment (static hosting with clean URLs)
