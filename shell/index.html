Shell Modules

Shell 00 and Shell 01 are the first modules you will tackle in the Piscine. They introduce the Unix command line — navigation, file operations, permissions, and shell scripting. Mastering these early gives you a strong foundation for the C modules and exams ahead.

Module Overview

Shell 00

Unix fundamentals: navigation, file operations, permissions, redirections, pipes, and wildcards.

Week 1Foundation

Shell 01

Shell scripting: variables, conditionals, loops, functions, environment manipulation, and permissions.

Week 1Foundation

Why Shell Matters

Daily Tool

You will use the terminal every single day of the Piscine — compiling, submitting, navigating, and debugging. Shell fluency saves hours of frustration.

Exam Foundation

Exam exercises often require shell commands for file manipulation, permission changes, and script writing. Shell knowledge directly impacts your exam performance.

Norm & Git

Checking Norminette, pushing with Git, and managing files all happen through the shell. Understanding the command line is non-negotiable from day one.

Quick Reference — Common Shell Commands

CommandDescriptionExample
lsList directory contentsls -la
cdChange directorycd /path/to/dir
cpCopy files or directoriescp src.txt dst.txt
mvMove or rename filesmv old.txt new.txt
rmRemove files or directoriesrm -rf dir/
chmodChange file permissionschmod 755 script.sh
findSearch for filesfind . -name "*.c"
grepSearch inside filesgrep "main" file.c
catConcatenate and display filescat file.txt
echoPrint text to stdoutecho "Hello"
envDisplay environment variablesenv | grep PATH
exportSet environment variableexport VAR=value
touchCreate empty file or update timestamptouch newfile
mkdirCreate directorymkdir -p a/b/c
headDisplay first lines of a filehead -n 20 file
tailDisplay last lines of a filetail -f log
wcCount lines, words, byteswc -l file.c
sortSort lines of textsort file.txt
uniqFilter repeated linessort f | uniq
diffCompare files line by linediff a.txt b.txt
patchApply a diff to a filepatch < file.diff
tarArchive filestar -czf archive.tar.gz dir/
