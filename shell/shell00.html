Shell 00 — Unix Basics

Shell 00 is your introduction to the Unix command line. You will learn how to navigate the filesystem, manipulate files and directories, manage permissions, use redirections and pipes, and work with wildcards. These skills are essential for every subsequent Piscine module and exam.

Concepts Covered

Navigation File Operations Permissions Redirections Pipes Wildcards Environment

Common Pitfalls

  • Permissions: Understanding octal (e.g., chmod 644) vs symbolic (chmod u+r) modes. The testShell00 exercise requires exact permissions.
  • Hidden files: Files starting with . are hidden. Use ls -a to see them. Some exercises expect hidden files.
  • ls flags: Memorize -l, -a, -R, -t, -r, -S. The midLS exercise requires a specific combination.
  • Patch format: diff -c or diff -u produce different patch formats. Make sure you use the expected format.
  • Magic file syntax: The file command uses a specific magic file format — offset, type, and expected bytes. Study man magic.
  • SSH keys: Use ssh-keygen -t rsa -b 4096. The public key goes in ~/.ssh/authorized_keys.
  • Git exercises: You need an initialized Git repository in your home directory for ex05 and ex06.
