Shell 01 — Scripting & Environment

Shell 01 builds on Shell 00 by introducing shell scripting. You will work with variables, conditionals, loops, functions, and environment manipulation. These exercises teach you to automate tasks and write reusable shell programs — a crucial skill for the Piscine and beyond.

Common Pitfalls

  • Syntax errors: Spaces around = in variable assignments (VAR=value is correct, VAR = value is not). A single wrong space breaks the script.
  • Shebang: Every script must start with #!/bin/bash (or #!/bin/sh). Without it, the script may not execute properly.
  • Permissions: Scripts need execute permission (chmod +x script.sh). The exercices expect you to set the correct permissions.
  • Environment vs local variables: Use export to make a variable available to child processes. Local variables (without export) are not inherited.
  • Command substitution: Use $(command) or backticks. The modern $() syntax is preferred and nests better.
  • Quoting: Always quote variables ("$VAR") to prevent word splitting and glob expansion. Unquoted variables cause subtle bugs.
  • Exit codes: Every command returns an exit code (0 for success). Use $? to check the last exit code in conditionals.
