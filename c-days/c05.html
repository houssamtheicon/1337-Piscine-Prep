C05 — Recursion & Math

C05 introduces recursion — a function calling itself — through mathematical problems. You will implement factorial (both iterative and recursive), power, fibonacci, prime detection, and the challenging ten queens puzzle. Strong understanding of base cases and stack frames is essential.

Common Pitfalls

  • Stack overflow: Deep recursion (e.g. fibonacci(1000000)) will overflow the call stack. Prefer iteration for large inputs or use tail recursion.
  • Base cases: Always define base cases first. For factorial: if (n <= 1) return (1);. For fibonacci: if (n <= 1) return (n);.
  • Integer overflow: Factorial grows extremely fast. 13! exceeds 32-bit int range. Return 0 for inputs that would overflow.
  • Negative input handling: Factorial and fibonacci of negative numbers are undefined. The subject typically expects you to return 0.

Peer-Eval Reminders

Check these during evaluation: Does ft_sqrt return the correct floor for non-perfect squares? Does ft_is_prime handle 0, 1, and 2 correctly? Does ft_ten_queens_puzzle actually count all 724 solutions? Are recursive functions properly terminated?
