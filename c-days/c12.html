C 12 — Singly Linked Lists

C 12 is the largest C module — it covers singly linked lists in depth. You will implement 17 functions that create, traverse, insert, delete, sort, and merge linked list nodes (t_list). Mastering C 12 is critical for the final exam.

Concepts Covered

Linked Lists t_list Nodes List Traversal List Insertion List Deletion List Sorting

Compile & Test

# Test basic operations
gcc -Wall -Wextra -Werror -o test_list ex00/ft_create_elem.c ex01/ft_list_push_front.c ex02/ft_list_size.c main.c

# Test sorting and merging
gcc -Wall -Wextra -Werror -o test_sort ex14/ft_list_sort.c ex16/ft_sorted_list_insert.c ex17/ft_sorted_list_merge.c main.c

# Check for memory leaks
valgrind --leak-check=full ./test_list
valgrind --leak-check=full ./test_sort

Common Pitfalls

  • NULL pointer dereference: Always check if a node or list pointer is NULL before accessing next or data.
  • Circular references: When reversing or sorting, ensure you do not create loops by incorrectly setting next pointers.
  • Memory leaks on deletion: In ft_list_clear, free each node's data (via free_fct) before freeing the node itself.
  • Sorting linked lists: Merge sort is the most efficient for linked lists. Bubble sort works but is slow for large lists.

Peer Evaluation Tip: This is the largest module — expect thorough testing. Run valgrind on every exercise. Test edge cases: empty lists, single-element lists, lists with duplicate values, and very long lists. Verify that ft_list_remove_if correctly frees removed nodes.
