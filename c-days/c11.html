C 11 — Function Pointers

C 11 introduces function pointers — a powerful feature that enables callback-based programming. You will implement higher-order functions like foreach, map, any, count_if, and is_sort, build a calculator (do-op), and write an advanced string sort using comparator callbacks.

Concepts Covered

Function Pointers Callback Functions foreach map sort

Exercises

0/8 (0%)
  • ex00: ft_foreach
    Apply a function to each element of an integer array
  • ex01: ft_map
    Create a new array by applying a function to each element (allocates)
  • ex02: ft_any
    Check if any element in a string array satisfies a condition
  • ex03: ft_count_if
    Count elements in a string array that satisfy a condition
  • ex04: ft_is_sort
    Check if an integer array is sorted according to a comparison function
  • ex05: do-op (basic)
    Simple calculator using function pointers for each operation
  • ex06: do-op (advanced)
    Extended calculator with more operations and better error handling
  • ex07: ft_advanced_sort_string_tab
    Sort a string array using a custom comparison function pointer

Compile & Test

# Test foreach
gcc -Wall -Wextra -Werror -o test_foreach ex00/ft_foreach.c main.c

# Test map
gcc -Wall -Wextra -Werror -o test_map ex01/ft_map.c main.c

# Test do-op
gcc -Wall -Wextra -Werror -o do-op ex05/ft_do-op.c
./do-op 42 + 10
./do-op 42 / 0

# Test advanced sort
gcc -Wall -Wextra -Werror -o test_sort ex07/ft_advanced_sort_string_tab.c main.c

Common Pitfalls

  • Function pointer syntax: int (*f)(int, int) is a pointer to a function returning int and taking two int params. Parentheses around *f are required.
  • Callback return types: Ensure the callback function signature matches the function pointer type exactly, including return type and parameters.
  • Array bounds in map: ft_map must allocate exactly the right size for the result array. Do not access beyond the array length.
  • Sort stability: The sort algorithm should be stable for ft_advanced_sort_string_tab. Bubble sort or insertion sort are commonly used.

Peer Evaluation Tip: Verify that function pointer parameters use the correct syntax. Test ft_map with valgrind to ensure no memory leaks. For do-op, test division by zero and invalid operators. Check that ft_is_sort returns 1 for empty and single-element arrays.
