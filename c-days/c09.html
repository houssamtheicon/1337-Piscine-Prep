C 09 — Makefiles & Libraries

C 09 introduces build automation with Makefiles and static library creation. You will write a Makefile that compiles a library (libft.a) and a more advanced Makefile with specific rules, flags, and relinking prevention.

Concepts Covered

Makefile Make Rules Static Libraries (.a) ar ranlib Object Files

Exercises

0/2 (0%)
  • ex00: libft.a
    Create a static library with a Makefile that compiles source files and archives them
  • ex01: Makefile
    Write a Makefile with specific variables (CC, CFLAGS), rules (all, clean, fclean, re), and relinking prevention

Compile & Test

# Build the library
make -C ex00
# Test linking against the library
gcc -Wall -Wextra -Werror -o test_prog main.c -L. -lft
# Clean build artifacts
make -C ex00 fclean
# Test the advanced Makefile
make -C ex01
make -C ex01 re

Common Pitfalls

  • CC vs gcc: Use CC as the compiler variable (not hardcoded gcc). The subject expects $(CC) with $(CFLAGS).
  • Missing $(CC) $(CFLAGS): Compile rules must use $(CC) $(CFLAGS) -c $< -o $@ pattern.
  • Wrong .c.o rule: The implicit suffix rule uses .c.o: with a leading dot. Use tab indentation.
  • Phony targets: Declare .PHONY: all clean fclean re to avoid conflicts with file names.
  • Relinking prevention: Use $< and $@ automatic variables so make only rebuilds when sources change.

Peer Evaluation Tip: Run make twice — the second run should produce Nothing to be done (relinking prevention). Check that the Makefile uses ar rcs (not ar rc or ar r) and that ranlib is called if required. Verify that make fclean removes both the object files and the library.
