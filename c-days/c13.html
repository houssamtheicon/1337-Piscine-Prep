C 13 — Doubly Linked Lists & Binary Trees

C 13 covers advanced data structures: binary trees using the btree node structure. You will implement tree creation, insertion, traversal (infix, prefix, postfix), search, deletion, and level counting — essential foundations for more complex algorithms.

Concepts Covered

Doubly Linked Lists Bidirectional Traversal btree Tree Structures btree Operations

Exercises

0/9 (0%)
  • ex00: btree_create_node
    Allocate and initialize a new binary tree node
  • ex01: btree_insert_data
    Insert data into a binary search tree in sorted order
  • ex02: btree_apply_infix
    Traverse a tree in infix order (left, node, right)
  • ex03: btree_apply_prefix
    Traverse a tree in prefix order (node, left, right)
  • ex04: btree_apply_postfix
    Traverse a tree in postfix order (left, right, node)
  • ex05: btree_search_item
    Search for a specific item in a binary search tree
  • ex06: btree_level_count
    Return the number of levels (height) in a binary tree
  • ex07: btree_insert_data_r
    Insert data using a pointer-to-pointer approach (advanced)
  • ex08: btree_apply_by_level
    Apply a function to each node organized by tree level

Compile & Test

# Test tree creation and insertion
gcc -Wall -Wextra -Werror -o test_tree ex00/btree_create_node.c ex01/btree_insert_data.c main.c

# Test tree traversals
gcc -Wall -Wextra -Werror -o test_traversal ex00/btree_create_node.c ex01/btree_insert_data.c ex02/btree_apply_infix.c ex03/btree_apply_prefix.c ex04/btree_apply_postfix.c main.c

# Test level count
gcc -Wall -Wextra -Werror -o test_levels ex00/btree_create_node.c ex01/btree_insert_data.c ex06/btree_level_count.c main.c

# Memory check
valgrind --leak-check=full ./test_tree

Common Pitfalls

  • Tree node child pointers: Always initialize left and right to NULL when creating a new node.
  • Recursion depth: Tree operations use recursion. Deep trees can cause stack overflow. Be mindful of the tree height.
  • Memory management: Every btree_create_node call allocates memory. Ensure you have a way to free the entire tree when done.
  • Balance assumptions: Basic BST insertion does not rebalance. The tree can become degenerate (linked list) if data is inserted in sorted order.

Peer Evaluation Tip: Test with balanced and degenerate trees. Verify that btree_level_count returns 0 for NULL and 1 for a single node. Check that btree_search_item returns NULL when the item is not found. Run valgrind to confirm no memory leaks.
