C Programming Modules

14 core C modules covering everything from basic output to linked lists. Each module builds on the previous.

C00 — Basic Output & Functions

Introduction to C programming — write your first functions, loops, and conditionals. Build fundamental output routines.

Week 1 Basic I/O Loops

C01 — Pointers & Memory

Master pointers, memory addresses, and references. Learn to swap values and manipulate data through pointers.

Week 1 Pointers Memory

C02 — String Manipulation

Build string utility functions — copy, compare, classify, and transform character arrays.

Week 1 Strings Character Classification

C03 — String Comparison & Memory

Implement string comparison, concatenation, and substring search functions.

Week 2 Strings Comparison

C04 — Advanced Strings & atoi

Build ft_atoi, ft_putnbr_base, and ft_atoi_base — string-to-number conversion and base representation.

Week 2 atoi Number Conversion

C05 — Recursion & Math

Dive into recursion with factorial, power, fibonacci, prime detection, and the ten queens puzzle.

Week 2 Recursion Math

C06 — Program Arguments

Work with argc and argv — access, display, reverse, and sort command-line arguments.

Week 2 argc/argv Sorting

C07 — Memory Allocation

Dynamic memory with malloc — duplicate strings, concatenate, and build arrays of variable size.

Week 3 malloc Memory

C08 — Headers & Structures

Organise code with header files, macros, and custom struct types.

Week 3 Headers Structures

C09 — Makefiles & Libraries

Create static libraries and automate compilation with Makefiles.

Week 3 Makefile Library

C10 — File I/O

Read and write files using file descriptors — implement cat, tail, and hexdump clones.

Week 3 File Descriptors I/O

C11 — Function Pointers

Pass functions as arguments — implement foreach, map, and sort with callbacks.

Week 4 Function Pointers Callbacks

C12 — Singly Linked Lists

Build and manipulate singly linked lists — create, insert, delete, and search.

Week 4 Linked Lists Dynamic Structures

C13 — Doubly Linked Lists

Advanced list operations with doubly linked lists — bidirectional traversal and complex insertions.

Week 4 Doubly Linked Lists Advanced
