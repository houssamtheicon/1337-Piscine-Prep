C02 — String Manipulation

C02 is all about string operations. You will implement functions that copy, compare, classify, and transform character arrays. This module builds heavily on the pointer skills from C01 and introduces memory-aware programming.

Common Pitfalls

  • Null terminator: Strings must end with '\0'. Forgetting it causes undefined behaviour when printing or comparing.
  • Buffer overflow: Ensure the destination buffer is large enough before copying. ft_strcpy does not check size — that is the caller's responsibility.
  • Non-printable characters: In ft_putstr_non_printable, remember that characters below 32 or above 126 are non-printable and should be displayed as \xHH.
  • Off-by-one in copy: Copy the null terminator too! ft_strncpy behaviour differs — it pads with nulls if source is shorter than n.

Peer-Eval Reminders

Check these during evaluation: Do all functions handle empty strings? Are classification functions returning 1 for true and 0 for false? Does ft_strcapitalize handle non-alphabetic separators correctly? Is the memory output in ft_print_memory properly formatted?
