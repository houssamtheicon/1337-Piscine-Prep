C 08 — Headers, Macros & Structures

C 08 teaches you to organize code using header files, preprocessor macros, and structures. You will create reusable headers with function prototypes, boolean macros, absolute value macros, point structures, and a stock information structure.

Concepts Covered

Header Files Macros (#define) Structures (struct) Typedef Include Guards Function Prototypes

Exercises

0/6 (0%)
  • ex00: ft.h
    Create a header file with all function prototypes from previous modules
  • ex01: ft_boolean.h
    Define TRUE, FALSE, and a boolean type using macros and typedef
  • ex02: ft_abs.h
    Define a macro ABS that returns the absolute value of a number
  • ex03: ft_point.h
    Create a t_point structure with x and y integer coordinates
  • ex04: ft_stock_str.h
    Define a t_stock_str structure containing size, string, and copy
  • ex05: ft_show_tab
    Write a function that displays the contents of a t_stock_str array

Compile & Test

# Test header inclusion
gcc -Wall -Wextra -Werror -o test_boolean ex01/ft_boolean.h main.c
gcc -Wall -Wextra -Werror -o test_abs ex02/ft_abs.h main.c
gcc -Wall -Wextra -Werror -o test_stock ex04/ft_stock_str.h ex05/ft_show_tab.c main.c

Common Pitfalls

  • Include guard missing: Always wrap header content with #ifndef HEADER_H / #define HEADER_H / #endif to prevent double inclusion.
  • Macro side effects: #define ABS(x) ((x) < 0 ? -(x) : (x)) — wrap parameters in parentheses to avoid operator precedence issues.
  • Struct typedef confusion: Use typedef struct s_point t_point; pattern consistently to avoid compilation errors.
  • Header dependency loops: Do not include header A from header B if B is also included from A. Use forward declarations when needed.

Peer Evaluation Tip: Verify that every header has proper include guards, macros wrap their arguments in parentheses, and structures use the correct typedef naming convention (prefix t_). Also check that ft_boolean.h uses the exact macro names expected by the tester.
