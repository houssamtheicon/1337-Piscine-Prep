C06 — Program Arguments

C06 teaches you to handle command-line arguments via the main(int argc, char **argv) signature. You will write programs that access, display, reverse, and sort the arguments passed to them. This module is relatively short but essential for understanding how C programs interact with their environment.

Concepts

argc argv Program Arguments Sorting

Exercises

0/0 (0%)
  • ex00: ft_print_program_name
    Display the program's name
  • ex01: ft_print_params
    Display all command-line arguments
  • ex02: ft_rev_params
    Display arguments in reverse order
  • ex03: ft_sort_params
    Sort and display arguments alphabetically

Compile & Test

# Compile any exercise as a program
cc -Wall -Wextra -Werror ex00/ft_print_program_name.c -o print_name

# Test with arguments
./print_name
./print_name hello world

# Test ft_sort_params
cc -Wall -Wextra -Werror ex03/ft_sort_params.c -o sort_params
./sort_param z b c a

Common Pitfalls

  • argv[0] is the program name: The first argument argv[0] is the program name itself, not the first user-provided argument. User arguments start at argv[1].
  • argc includes the program name: If you run ./a.out one two, argc is 3 (./a.out, one, two), not 2.
  • Null termination of argv: argv[argc] is guaranteed to be NULL. You can use this as a sentinel in loops.
  • Sorting strings: Use ft_strcmp (or a local implementation) to compare strings. Remember that strcmp returns 0 when equal.

Peer-Eval Reminders

Check these during evaluation: Does the program compile as a standalone executable? Does it use the correct main signature? Does ft_print_program_name display only the name (not the path)? Does ft_sort_params handle duplicate arguments? Are arguments printed each on a separate line?
