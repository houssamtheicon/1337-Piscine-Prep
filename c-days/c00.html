C00 — Introduction to C

C00 is your first contact with C programming. You will learn how to write functions, use loops and conditionals, and display output using ft_putchar. By the end of this module you will be comfortable with basic control flow and function creation.

Concepts

ft_putchar Loops Conditions Functions Basic I/O

Exercises

Compile & Test

# Compile all exercises
cc -Wall -Wextra -Werror ex00/ft_putchar.c -o test_putchar

# Test with a main
echo 'int main(void){ft_putchar("H");return 0;}' > main.c \
  && cc -Wall -Wextra -Werror main.c ex00/ft_putchar.c -o test \
  && ./test

Common Pitfalls

  • Off-by-one in loops: Remember C arrays are 0-indexed. A loop iterating through 26 letters should go from 0 to 25, not 1 to 26.
  • putchar vs printf: The subject requires ft_putchar (which uses write), not printf. Using printf will get you a -42.
  • Infinite loops: Make sure your while or for loop condition eventually becomes false. Test with small ranges first.
  • char vs int: Characters are small integers. '0' is not the same as 0 — their ASCII values differ by 48.

Peer-Eval Reminders

Check these during evaluation: Does the code compile with -Wall -Wextra -Werror? Is the Norm respected (no more than 25 lines per function, proper indentation)? Does ft_putchar use write(1, &c, 1)? Are functions tested with edge cases (max/min int, negative numbers, empty input)?
