C01 — Pointers

C01 introduces pointers — one of the most important concepts in C. You will learn how to access memory addresses, modify variables through pointers, and work with arrays. Mastering pointers here is essential for every module that follows.

Common Pitfalls

  • Dereferencing null: Always check that a pointer is not NULL before dereferencing it. Dereferencing NULL causes a segfault.
  • Pointer arithmetic: ptr + 1 moves by sizeof(type) bytes, not 1 byte. For int* this moves 4 bytes.
  • Forgetting &: To pass the address of a variable to a function that expects a pointer, use &var, not var.
  • Modifying original values: Without pointers, functions receive copies. Use pointers when the caller expects the original to change.

Peer-Eval Reminders

Check these during evaluation: Are pointers used correctly and not dereferenced without checking? Does ft_swap actually swap the original values (test from main)? Is the Norm followed — no more than 4 parameters per function? Do array exercises handle empty or single-element arrays?
