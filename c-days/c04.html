C04 — Advanced Strings & ft_atoi

C04 combines string operations with number conversion. The star of this module is ft_atoi, which converts a string to an integer while handling whitespace and signs. The later exercises ft_putnbr_base and ft_atoi_base extend these skills to arbitrary base systems.

Concepts

ft_atoi String Display ft_putnbr_base ft_atoi_base

Common Pitfalls

  • Handling whitespace in atoi: ft_atoi must skip leading whitespace (spaces, tabs, newlines) before parsing the number. The standard allows any character where isspace() is true.
  • Sign overflow: When converting "-2147483648", the positive value 2147483648 overflows a 32-bit int. Handle this by accumulating into a long or checking boundaries.
  • Base validation in putnbr_base: The base must have at least 2 characters, contain no duplicates, and no plus/minus signs. Check all constraints before proceeding.
  • Negative numbers in putnbr_base: Print a minus sign first, then convert the absolute value to the target base.

Peer-Eval Reminders

Check these during evaluation: Does ft_atoi handle multiple signs like "--42" or "+-42"? Does ft_putnbr_base correctly reject invalid bases? Are edge cases like INT_MIN, empty strings, and base of size 2 tested?
