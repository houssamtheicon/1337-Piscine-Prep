The Piscine — 4 Weeks

The Piscine is an intensive, month-long immersion in programming. You will code daily, work in teams on weekends, and sit timed machine exams weekly. Here is how a typical session is structured:

1

Week 1 — Foundations

  • Shell 00 — Unix basics, navigation, files
  • Shell 01 — Scripting, environment, permissions
  • C 00 — First C programs, putchar, loops
  • C 01 — Pointers and basic memory
  • Exam 00 — First machine exam
  • Rush 00 — Weekend group project
2

Week 2 — Strings & Functions

  • C 02 — String manipulation
  • C 03 — String comparison, memory
  • C 04 — ft_atoi, advanced strings
  • C 05 — Recursion, math
  • Exam 01 — Second machine exam
  • Rush 01 — Weekend group project
3

Week 3 — Memory & Structures

  • C 06 — argc, argv
  • C 07 — malloc, string duplication
  • C 08 — Headers, macros, structs
  • C 09 — Makefiles, libraries
  • Exam 02 — Third machine exam
  • Rush 02 — Weekend group project
4

Week 4 — Advanced & Final

  • C 10 — File descriptors, I/O
  • C 11 — Function pointers
  • C 12 — Linked lists
  • C 13 — Advanced structures
  • Final Exam — End-of-Piscine exam
  • Peer evaluations & polishing
